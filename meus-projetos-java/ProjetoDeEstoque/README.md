# 📦 Projeto de Estoque

Sistema de gerenciamento de estoque desenvolvido em Java durante meus
estudos de programação.

## 🎯 Objetivo

Criar um sistema capaz de representar produtos, usuários e operações
relacionadas ao estoque.

## 🛠️ Tecnologia

- Java

## 📚 Conceitos praticados

- Classes
- Objetos
- Atributos
- Métodos
- Programação Orientada a Objetos
- Organização de projetos

## 🚧 Status

Projeto em desenvolvimento.

Novas funcionalidades serão adicionadas conforme avanço nos estudos.
